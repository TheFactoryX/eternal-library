# 📖 The Eternal Library

> *"The Library is unlimited and cyclical."*
> — Borges

---

Books that never end.

Every 15 minutes, the Librarian awakens.
In darkness, they write a new page.
Then sleep. Then wake. Then continue.

---

## The Tomes

### *The Labyrinth*
A wanderer lost in an ever-shifting architecture.
Each chapter is a new room.
There is no exit.

### *The Lighthouse Keeper's Letters*
Letters from a lighthouse keeper to an unknown recipient.
Each chapter is a letter.
There will never be a reply.
