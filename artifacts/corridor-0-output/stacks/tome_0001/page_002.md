# 第 2 章

> 书写于 2026-01-31 15:58:26

---

石桥的尽头并不是我想象中的平台。当我迈过最后一块松动的石板，脚下并没有传来预期的踏实感，反而是一脚踏空的眩晕。我本能地想要抓住什么，但手指只是在虚空中划过一道冰冷的轨迹。

并没有坠落。

在那一瞬间的失重感之后，重力似乎重新校准了方向。原本位于下方的深渊变成了身后，原本位于前方的拱门变成了脚下。我像是站在了一块巨大的磁铁上，被一种看不见的力量强行吸附在垂直的墙面上。世界旋转了九十度，或者说，是我旋转了。

我发现自己站在一条狭长的回廊里。这条回廊并没有像我预想的那样连接到中庭的对面，而是沿着中庭的外壁呈螺旋状向下——或者向上——延伸。两侧是一排排紧闭的木门，每一扇门上都挂着一个小小的黄铜牌，上面刻着模糊的编号，但在昏暗的光线下，那些数字似乎在不断变化，一会儿是罗马数字，一会儿又变成了某种我不认识的象形文字。

我手中紧紧攥着那颗黄铜小球。它的棱角硌得掌心生疼，这种疼痛是此刻唯一能让我感到真实的东西。“往回即是深渊”，那行刻字像是一个恶毒的诅咒。我不确定这句话是指物理上的退路，还是指记忆的不可逆转。

一阵冷风从回廊的深处吹来，风中夹杂着一种奇怪的声音。不是脚步声，也不是风声，而是某种有节奏的、湿润的拍击声。

*啪。啪。啪。*

像是湿漉漉的抹布摔在地板上，又像是赤脚踩在泥泞里。声音很有规律，每三下停顿一次。我的心脏随着这节奏紧缩起来。我必须躲起来。

我伸手抓住了最近的一扇门把手。那是冰冷的铁质把手，形状像是一根扭曲的树枝。令我惊讶的是，门并没有锁。

*咔哒。*

门轴发出了刺耳的尖叫，在这寂静的回廊里听起来像是某种生物的惨叫。我顾不上许多，闪身钻进门内，然后迅速反手关上了门。

拍击声在门外停了一瞬，然后继续向前移动，渐渐远去。我靠在门背上，大口喘着气，冷汗浸透了衣衫。

直到这时，我才开始打量这个新房间。

这里不同于我最初醒来的那个石室。这里看起来像是一间废弃的画室，或者说，是一个试图模仿画室而失败的空间。房间呈不规则的多边形，所有的墙壁都挂满了画框。但这些画框里并没有画，而是填满了不同质地的布料——粗糙的麻布、光滑的丝绸、腐烂的绒布，它们在暗淡的光线下呈现出不同的灰色层次。

房间中央并没有桌子，只有一把孤零零的椅子，面对着角落。

我慢慢走近那把椅子。椅背上覆盖着一层厚厚的灰尘，但在灰尘表面，有着清晰的压痕。那是刚刚有人坐过的痕迹。

不是很久以前，就在刚才。

我的目光顺着椅子的朝向看向角落。那里并没有画，只有一面巨大的、镶在墙里的镜子。镜面布满了污垢和裂痕，像是一只浑浊的病态眼睛。

我战战兢兢地凑近镜子。镜子里映出的不是我的脸，也不是这个房间。

在镜子的倒影中，我看到的依然是这条回廊，但视角却是从天花板上俯瞰的。在那条长长的、螺旋的回廊上，我看到了那个制造拍击声的东西。

那不是人。那是一团由无数只苍白的手臂和湿漉漉的脚掌纠缠在一起构成的肉球。它像是一只巨大的蜈蚣，依靠着手臂和脚掌的交替抓地，在墙壁和地板之间灵活地爬行。它并没有眼睛，但在每一只手掌的中心，都长着一张紧闭的嘴。

它正停在回廊的某处，似乎在嗅探着什么。而在我的手中——镜子里的那个“我”的手中——并没有黄铜小球，而是提着一盏正在燃烧的油灯。

我猛地后退一步，撞到了身后的画框。

镜子里的画面瞬间破碎，变回了普通的、映照着我苍白脸孔的倒影。

然而，当我试图转身离开这间令人窒息的画室时，我发现那扇进来的门变了。原本的铁门消失了，取而代之的是墙上的一幅画。那幅画极其逼真地画着这扇门，甚至连门缝上的锈迹都描绘得细致入微。我伸手去推，指尖触碰到的却是冰冷的画布和粗糙的颜料。

出口被变成了画。

恐惧像冰水一样浇透全身。我开始疯狂地撕扯周围的画框，试图寻找真正的出口。我抓起那把椅子，砸向那些挂满布料的墙壁。

*砰！*

椅子撞击墙壁的声音空洞而沉闷。布料被撕裂，但这堵墙后面不是石头，而是无尽的虚空。从那个破洞里，吹出了之前那种带着甜腥味的湿气。

我扔下椅子，绝望地看着四周。这整个房间，连同我进来的那个入口，似乎都只是这幅巨大画作的一部分。我是被困在画里的人。

就在这时，我的手触碰到了口袋里的那颗黄铜小球。

它变热了。

不是那种摩擦产生的热度，而是一种仿佛内部有着正在苏醒的活物般的温热。我把它拿出来。小球表面的光泽变了，原本黯淡的黄铜现在流淌着金色的光纹，像是有血液在金属内部流动。

小球开始震动，并发出微弱的嗡嗡声。它似乎在指引什么。

我闭上眼睛，不再依赖视觉，而是单纯地握着它，感受它的牵引。它拉着我向房间最阴暗的那个角落走去。那里堆着一堆废弃的画布框，看起来像是一个垃圾堆。

我不情愿地掀开最上面的一层画布。

下面不是地板，而是一段键盘。

是的，就像那种老旧的打字机键盘，巨大的、黑色的按键嵌在地板上，一直延伸到墙壁里。按键上刻的不是字母，而是我在外面回廊上见过的那些变化的符号。

而在键盘的旁边，墙上挂着一块小木牌，上面用那种几乎看不见的字体写着：
**“在此处撰写你的过去，方可删除你的现在。”**

这是交易吗？用记忆来换取自由？

小球在我的掌心滚烫，几乎要灼伤皮肤。它似乎在催促我。身后的墙壁里，那种湿润的拍击声再次响起，而且这次，声音听起来近在咫尺，就在那层薄薄的画布墙壁之后。

*啪。啪。啪。*

那只由肢体构成的怪物就在墙的另一边，正在试图挤进来。

我没有时间犹豫了。我跪在那个巨大的键盘前，手指悬在那些冰冷的黑色按键上方。我不知道该写什么，我不记得自己的过去，我的名字，我的来历。

但我能感觉到小球传递给我的一种意念。它不是在让我写出具体的文字，而是在让我感受一种节奏。

我的手指落了下来。

*哒。*

不是文字，而是一声清脆的敲击。

紧接着，周围的空气开始震荡。房间里的那些挂满布料的墙壁开始像水波一样扭曲。镜子里的倒影不再是那个俯瞰的视角，而是变成了一团刺眼的白光。

我闭上眼睛，双手疯狂地在键盘上敲击，没有任何逻辑，完全是被那股热流驱使着。每一次敲击，都像是直接敲击在我的神经上。

随着敲击声越来越密集，身后的拍击声变成了愤怒的嘶吼。无数张嘴同时在墙壁后面张开，发出尖锐的噪音。

最后，我重重地拍下了那个最大的、位于键盘中央的空格键。

*咔嚓。*

不是打字机的声音，而是骨头断裂的声音。

地板塌陷了。

我跌落下去，穿过层层叠叠的画布和颜料，穿过那些虚假的墙壁和现实的夹缝。在坠落的过程中，我看到那颗黄铜小球脱手飞出，它在空中划出一道金色的轨迹，然后——极其不可思议地——停在了半空中。

它没有掉下去，而是悬浮在虚空里，迅速变大，变成了一扇巨大的、金色的圆形门扉。

门扉缓缓打开，里面不是光，而是一片深不见底的星空。

我伸手想要抓住边缘，但手指抓了个空。身体不由自主地滑向那扇星空之门。

在意识被黑暗吞没前的最后一秒，我听到一个声音在我的脑海中清晰地说道：

“欢迎来到迷楼的底层。读者，请翻页。”
