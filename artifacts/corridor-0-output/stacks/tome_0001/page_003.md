# 第 3 章

> 书写于 2026-01-31 16:04:41

---

坠落感消失的那一刻，我并没有感受到预想中的撞击。相反，身体像是被某种粘稠的液体包裹，然后被温柔地放置在了坚硬的地面上。

那扇星空之门并没有带我前往宇宙深处，或者某个异维度空间。当我睁开眼，重新适应四周的光线时，我发现自己站在一条宽阔得近乎荒谬的走廊里。

这里不再是那种幽闭的岩石或者木质结构。脚下的地板铺满了黑白相间的大理石，光亮得能映照出人影。两侧的墙壁高达十几米，并非实体的墙壁，而是由无数个巨大的、黑胡桃木做的书架紧密排列而成。书架一直延伸到视线尽头的阴影里，仿佛两座连绵起伏的山脉。

空气中弥漫着一股古老的气味——那是纸张腐烂、墨水干涸和皮革老化混合在一起的味道。这是一种知识死亡后的尸臭味。

我站起身，拍了拍衣服。那颗黄铜小球不见了，口袋里空空如也。这让我感到一种莫名的不安，仿佛失去了在这座建筑中唯一的导航灯。

但我没时间去寻找它。因为这里太安静了。这种安静不同于那个有沙漏的房间，那里的安静是凝固的；这里的安静是充满压迫感的，仿佛有无数双眼睛藏在那些书架的缝隙里，正死死地盯着我。

我走向离我最近的一个书架。书架上塞满了厚重的书籍，每一本书的装帧都极其奢华，封面材质各异，有的像是某种爬行动物的皮，有的则呈现出金属的光泽。但奇怪的是，这些书都没有名字。

我抽出一本深蓝色的书。封面上烫金的纹路已经褪色，摸起来有一种粗糙的颗粒感。我翻开第一页。

书页里没有文字，只有一张被精细描绘的地图。

那是一张人体构造图，但图上标注的不是器官或骨骼，而是一座座微缩的建筑。大脑的位置是一座高塔，心脏的位置是一个中央庭院，而在胃部——那原本应该是消化的地方——画着一个螺旋向下的迷宫。

在图注的位置，有一行用墨水手写的小字，字迹潦草且充满了恐慌：
*“第三层的记忆被墙体消化了。”*

我感到背脊一阵发凉，迅速合上书，把它塞回原处。手刚松开，身后就传来了一阵细微的摩擦声。

*沙——沙——*

那是手指划过纸张的声音。

我猛地转身，身后空无一人。只有那一排排书架像墓碑一样静默矗立。但那声音并没有消失，它开始变得立体，似乎是从四面八方传来的。无数只看不见的手正在无数本书脊上划过。

*沙——沙——*

声音越来越大，甚至盖过了我的呼吸声。我不确定这是某种机关运作的声响，还是这座建筑本身在阅读着什么。恐惧再次袭来，那是对未知的本能畏惧。我必须离开这条走廊。

我开始奔跑。脚下的黑白大理石地砖飞速后退，两旁的书架连成了一片模糊的残影。我跑了很久，久到肺部开始燃烧，但眼前的景象丝毫没有变化。这条走廊似乎是无限的，或者是一个巨大的莫比乌斯环。

就在我即将力竭的时候，我终于看到了不一样的东西。

在走廊的尽头，有一张巨大的、横跨了整个宽度的桌子。那张桌子大得像是一块平原，上面堆满了散乱的纸张、墨水瓶和鹅毛笔。而在桌子正中央的高背椅上，坐着一个人——或者说，一个影子。

那人影穿着一身维多利亚时代的黑色长礼服，背对着我，肩膀随着某种节奏微微耸动。

我放慢脚步，试探性地向前走了几步。

“你是谁？”我的声音在空旷的走廊里回荡，显得单薄而无力。

那人影停止了动作。并没有声音传来，但我能感觉到某种无形的视线穿透了椅背，落在我身上。

紧接着，一个声音直接在我的脑海中响起，不是语言，而是一种类似翻书页的声响组成的意念：
*“读者，还是误入者？”*

那声音冰冷、干燥，不含任何情感。

“我是……迷路了。”我回答，喉咙干涩，“我想出去。”

椅子缓缓转了过来。

我倒吸了一口凉气。那不是人。那椅子上坐着的，是一个由无数本旧书堆砌而成的形体。它的头是一本巨大的、封面破损的《法典》，身体是由成千上万卷羊皮纸捆扎而成的，而它的手——如果那能被称为手的话——是两根正在挥舞的巨大鹅毛笔。

它没有脸，但在那本《法典》翻开的书页上，有两行不断变换的文字，像是眼睛在眨动。

*“出去需要代价。”* 它写道。与此同时，其中一根鹅毛笔在空中的纸张上飞快地记录着什么。*“你删掉了一章过去，现在需要补上一次叙述。”*

“叙述什么？”

*“叙述这座建筑的温度。”* 它的回答依旧是由书页翻动的声音构成的。

还没等我理解这句话的含义，那个书堆巨人突然将那根巨大的鹅毛笔指向了我。笔尖沾满了漆黑的墨水，那墨水并不顺流而下，而是违背重力地向空中喷洒，化作无数黑色的乌鸦。

那些乌鸦并不是实体，而是由墨水构成的平面图形。它们尖叫着向我冲来，翅膀扇动时散落下黑色的粉末。

我本能地向后退，想要逃离这张桌子，但我发现身后的地板正在发生变化。原本坚硬的大理石变得柔软、湿润，那黑白相间的格子变成了某种巨大生物的表皮。地板在蠕动，仿佛我正站在一个沉睡巨人的肚皮上。

“我该怎么叙述？”我大声喊道，试图盖过乌鸦的尖啸声。

巨人那由《法典》构成的头颅微微倾斜，书页疯狂翻动，最终停留在某一页：
*“描述你感受到的恐惧。不要用形容词，要用名词。”*

乌鸦已经逼近，黑色的墨水即将溅到我的脸上。我闭上眼睛，强迫自己冷静下来。恐惧？这里的恐惧不是怪兽追逐，而是这种无处不在的、令人窒息的荒谬感。

我张开嘴，声音颤抖着吐出词汇：
“生锈的时钟。发霉的面包。走廊尽头的镜子。没有面孔的画像。无法抵达的出口。被吞噬的记忆……”

随着每一个名词的吐出，空中的墨水乌鸦就掉落一只，化作一滩黑水消失在地板上。当我停下来时，周围重新恢复了死寂。

我睁开眼。那个书堆巨人依然坐在那里，但它的动作变得迟缓了。它面前的那张空白的纸上，写满了我刚刚说出的词汇。

*“叙述合格。”* 它的意念中带着一丝不易察觉的疲倦。*“你可以通过。但记住，迷楼只记录真实，不负责解释。”*

随着这行文字在它脸上显现，那张巨大的桌子开始从中间裂开。就像是一本书被合上了，两边的桌板向下翻转，露出了一条向下的通道。

那是一条滑梯，或者说，一条食道。内壁覆盖着某种红色的、类似天鹅绒的材料，但在昏暗的光线下，那看起来更像是某种内脏的内壁。

巨人挥动了鹅毛笔，示意我下去。

我站在裂缝边缘，犹豫了。下去？去哪里？

但我别无选择。身后的书架开始摇晃，无数本书像雪崩一样掉落，砸在地板上发出雷鸣般的声响。这座巨大的图书馆正在崩溃，或者说，它正在赶人。

我深吸一口气，纵身跳进了那条红色的通道。

滑行的速度极快，四周红色的内壁摩擦着我的身体，产生出巨大的热量。这种滑行没有任何逻辑，我忽而向左，忽而向右，甚至有一段时间是头朝下倒滑着的。

在一片混乱的眩晕中，我看到通道的内壁上开始出现画面。不是静止的画，而是像电影一样的连续影像。

我看到了我自己。

影像中的我正坐在某个咖啡馆里，手里拿着一本书，神情专注。阳光洒在我的脸上。然后，画面一闪，我看到了自己走在雨夜的街道上，撑着一把黑色的伞。接着，是我站在一个地铁站台上，等待着永远不会到来的列车。

这些场景如此熟悉，却又如此遥远。那是我的过去吗？是被这座建筑吞噬的记忆吗？

就在我试图伸手去触碰那个雨夜中的自己时，滑行戛然而止。

我像是一块被吐出来的果核，被甩在了一层冰冷且充满弹性的膜上。

这里很黑，只有远处有一盏忽明忽暗的煤油灯。空气中充满了硫磺和铁锈的味道。

我挣扎着爬起来，发现自己身处一个巨大的、类似钟表内部的空间。四周布满了巨大的齿轮，它们咬合在一起，发出轰隆隆的巨响。但在这些齿轮的缝隙中，我看到有一些微小的身影在忙碌地穿梭。

那是一些只有巴掌大小的人形生物，它们穿着破旧的工作服，正拿着扳手和锤子，在巨大的齿轮上敲敲打打。

我还没站稳，其中一个生物就发现了入侵者。它吹了一声口哨，尖锐的哨声瞬间盖过了齿轮的轰鸣。

所有的微小生物同时停下了手中的工作，齐刷刷地转过头看向我。
